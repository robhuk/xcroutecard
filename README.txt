ROUTE CARD APP

This package contains an offline-first installable web app.

To use:
1. Upload these files to any HTTPS web host, or run them through a local web server.
2. Open the app in Safari on iPhone.
3. Use Share > Add to Home Screen.

Data is stored locally in the browser on the device. Export Backup creates a JSON backup file.

The included app icon is the Route Card icon supplied for this project.

Updated status thresholds: 0–91 days Green, 92–150 days Amber/Yellow, 151+ days Red.
Individual coverage history entries can be deleted from an expanded route card.

Latest update: Method options include Booked RR Day and Other. A status key is displayed at the bottom of the main Route Card page.
